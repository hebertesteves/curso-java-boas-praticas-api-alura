# 📘 Curso Java — Boas Práticas de Programação

Repositório criado para armazenar os códigos, exemplos e práticas desenvolvidas durante o curso **Boas práticas de programação: melhore o código de uma API Java**, da **Alura**.

Este projeto tem como objetivo consolidar conceitos de **boas práticas de programação, refatoração e arquitetura de aplicações Java**, com foco na melhoria da qualidade do código, separação de responsabilidades e otimização de APIs.

---

## 🧠 Conteúdos abordados

Durante o curso, foram estudados os seguintes tópicos:

- Identificação de más práticas em projetos Java
- Separação de responsabilidades entre classes e camadas
- Refatoração de código
- Extração da camada Service
- Extração de funcionalidades para classes específicas
- Aplicação do padrão **Data Transfer Object (DTO)**
- Implementação de validações flexíveis
- Aplicação de padrões de projeto
- Organização e estruturação de APIs Java
- Otimização de consultas ao banco de dados
- Melhoria da manutenibilidade e legibilidade do código
- Boas práticas de desenvolvimento backend
